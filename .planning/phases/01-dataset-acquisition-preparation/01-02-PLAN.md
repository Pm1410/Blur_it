<task id="01-02-02" type="auto">
<name>Implement perceptual hashing deduplication</name>
<files>
- src/data/dedup.py
</files>
<action>
1. Author `src/data/dedup.py` with perceptual hashing using `imagehash.phash()`.
2. For each image, calculate a 64-bit DCT pHash.
3. Compare hashes using Hamming distance ($\le 4$ considered near-duplicate).
4. Remove duplicate entries globally across the raw dataset, keeping one canonical instance per duplicate group.
5. Export deduplication summary with original count, duplicates removed, and unique count.
</action>
<verify>
Create synthetic duplicates (e.g. rescaled or slight JPEG recompression) and verify `dedup.py` flags and removes near-duplicates.
</verify>
<acceptance_criteria>
Duplicate and near-duplicate images are removed, and a set of distinct images with distinct pHashes is retained.
</acceptance_criteria>
</task>

   `len(set(train_hashes).intersection(test_hashes)) == 0`

5. Write `data/processed/dataset_report.json` documenting total images, class distribution counts per split, percentages, and `leakage_detected: false`.
6. Author `src/data/prepare_dataset.py` tying together download, clean, dedup, split, and report generation into a single command-line interface.
</action>
